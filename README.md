# Xelqo homepage starter

A responsive, single-page Xelqo website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and copy
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year

## Preview locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the free VS Code extension **Live Server**.
3. Check the page at desktop and mobile widths.

## Before publishing
- The contact link currently uses `YOUR_EMAIL_HERE` as a placeholder. Replace it with an email address you control.
- Confirm that the Xelqo name and any domain/social handles are available before investing in the brand.
- Review all service descriptions so they accurately reflect what you can currently deliver.
- The two portfolio cards link to your existing live demo apps. They are explicitly described as demonstrations, not production deployments.

## Free hosting
This static site can be published with GitHub Pages. No build step or paid API is required.

The header, footer and standalone SVG logo use the uppercase XELQO wordmark.
